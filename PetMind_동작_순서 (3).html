PetMind 동작 순서

보호자가 외출 모드를 켜는 순간부터 짖음 알림과 음악 명령까지, 누가 언제 무엇을 하는지 11단계로 보여 줍니다. 왼쪽 칸은 보호자의 행동, 가운데는 PC에서 도는 프로그램, 오른쪽은 외부 장치와 클라우드입니다.

범례: 실선 상자는 구현·검증한 부분, 점선 상자는 가상 실행입니다. 왼쪽 칸의 옅은 색 상자는 보호자가 직접 하는 행동입니다. 왼쪽 가장자리 화살표(⑤ → ⑩)는 지속 짖음 알림이 만든 음악 제안이 승인으로 이어지는 경로입니다. 초록 점은 데이터·명령이 이동하는 모습입니다. 키보드 ← → 로 단계를 넘기고 Space로 재생/정지합니다.
