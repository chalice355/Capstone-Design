# 실습과제
| 기능 | 단축키 |
| --- | --- |
| 문자단위 커서 이동 -> 앞, 뒤, 맨앞, 맨뒤 | Ctrl+f, Ctrl+b, Ctrl+a, Ctrl+e |
| 단어단위 커서 이동 -> 앞, 뒤 | Alt+f, Alt+b |
| 현재 위치 문자 삭제 | Ctrl+d |
| 뒤에 있는 문자 삭제 | Ctrl+h |
| 뒤에 있는 단어 삭제 | Ctrl+w |
| 자르기 및 붙여넣기 | Ctrl+k 또는 u, Ctrl+y |
| 화면 잠금 및 해제 | Ctrl+s, Ctrl+q |
| 실행 종료 | Ctrl+c |
| 화면 삭제 | Ctrl+l |
